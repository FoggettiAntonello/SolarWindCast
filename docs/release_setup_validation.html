Installazione isolata e demo funzionanti

Nessuna nuova previsione reale: le metriche scientifiche restano invariate. Questa pagina verifica installazione, comandi e ripetibilità di una demo sintetica.

Esito del collaudo

  • Nuova venv Windows / Python 3.12.10, senza pacchetti condivisi con l'ambiente di lavoro.
  • Dipendenze reinstallate da wheel locali; solo setuptools 78.1.0 scaricato (1,3 MB). PyTorch 2.11.0+cu128.
  • 370 test superati; una prova opzionale con pesi esclusa. pip check e Ruff senza errori.
  • Wheel SolarWindCast installata normalmente; importazione isolata fuori dal repository riuscita.
  • Demo dalla CLI installata: tre baseline, tre finestre di otto ore, nessun token, rete o peso durante l'esecuzione. CLI inspect --help riuscita.
  • Wheel ispezionata: solo codice e metadati, senza osservazioni reali, token o pesi.

Limiti: non è un nuovo download completo da Internet, né un collaudo dell'installazione CPU o di altri sistemi operativi. Timestral è installato dalla wheel locale del commit fissato; nessuna nuova inferenza Timestral eseguita.

Prima e dopo: stessa demo sintetica

Prima: ambiente di lavoro. Dopo: pacchetto installato nella nuova venv. Stessi dati, seed e configurazione. I riepiloghi completi coincidono. Un valore target mancante resta escluso dalle metriche puntuali: 23 casi usati su 24; le metriche dei quantili riportano il proprio conteggio.

MAE, RMSE e pinball: più bassi sono migliori; bias ideale zero. Errori e ampiezze sono in MW, copertura espressa come frazione da confrontare con il livello nominale. L'ampiezza va letta insieme alla copertura. Non sono risultati di Timestral su dati reali.
